# Élan Fitness — Site multipage

Migration d'un site one-pager vers un site multipage : **Accueil**, **Programmes**, **À propos** et **Contactez-nous**.

## Stack

- HTML5 + CSS3
- Responsive design
- Aucune dépendance

## Démarrage

Ouvrir `index.html` dans un navigateur.
